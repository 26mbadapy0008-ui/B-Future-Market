# B Future Market

Starter e-commerce website for B Future Market.

## Current version
- Responsive homepage
- Product catalogue
- Product search
- Cart
- Basic price display
- GitHub-ready folder structure

## Next development
1. Backend/API
2. Database
3. Admin panel
4. User accounts
5. Payment gateway
6. Shipping/order tracking
7. Marketplace integrations (Amazon, Flipkart, Myntra and others)

## Run locally
Open `frontend/index.html` in a browser.

For production, connect the frontend to a backend/database and configure payment, authentication, inventory and marketplace APIs.
